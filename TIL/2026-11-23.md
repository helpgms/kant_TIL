## 1장. 인공지능과 머신러닝의 이해

### 1. 머신러닝이란?

머신러닝(Machine Learning)은 컴퓨터가 데이터를 학습하여 패턴을 찾고, 이를 바탕으로 예측하거나 판단하는 기술이다.

**머신러닝 활용 사례**
- 내비게이션의 교통량 예측 및 경로 추천
- 스마트워치의 활동 데이터 분석
- 스팸 메일 자동 분류
- 상품 및 콘텐츠 추천 알고리즘

### 2. AI의 4계층

인공지능 기술은 다음과 같은 포함 관계로 이해할 수 있다.

```text
AI (인공지능)
 └── ML (머신러닝)
      └── DL (딥러닝)
           └── 생성형 AI (Generative AI)
                └── LLM (대규모 언어 모델)
```

※ 개념을 이해하기 위한 단순화된 구조이다. 생성형 AI 전체가 딥러닝에만 속하는 것은 아니며, LLM은 주로 언어를 처리하고 생성하는 모델이다.

| 구분 | 설명 | 활용 사례 |
|---|---|---|
| AI | 인간의 지능적 작업을 수행하는 기술 | 규칙 기반 챗봇 |
| ML | 데이터를 학습하여 예측·분류 | 스팸 메일 필터링 |
| DL | 다층 신경망을 활용한 학습 | 얼굴 인식 잠금 해제 |
| 생성형 AI | 새로운 콘텐츠를 생성 | 이미지·텍스트 생성 |
| LLM | 대규모 언어 데이터를 학습한 모델 | 대화형 AI |

### 3. AI의 발전과 Transformer

**Transformer(트랜스포머)** 는 2017년에 발표된 신경망 아키텍처로, 현대 LLM 발전에 중요한 역할을 했다.

핵심 기술은 Self-Attention(셀프 어텐션)이다.

- 문장 내 토큰 간 관계를 계산한다.
- 각 토큰이 다른 토큰을 얼마나 참고해야 하는지 가중치를 구한다.
- 학습 과정에서 병렬 연산을 효율적으로 활용할 수 있다.

### 4. Foundation Model(파운데이션 모델)

파운데이션 모델은 대규모 데이터를 사전 학습하여 다양한 작업에 활용할 수 있도록 만든 기반 모델이다.

하나의 기초 모델을 여러 서비스나 목적에 맞게 활용할 수 있다.

### 5. AI 리터러시와 비판적 문해력

AI의 답변을 무조건 신뢰하기보다 비판적으로 검토하는 능력이 중요하다.

**주의할 점**

- AI의 답변은 항상 사실이라고 보장할 수 없다.
- 환각(Hallucination)으로 인해 그럴듯하지만 잘못된 정보를 생성할 수 있다.
- 중요한 정보는 출처 확인과 교차 검증이 필요하다.
- 개인정보와 영업 비밀 등 민감한 정보를 함부로 입력하지 않아야 한다.

**RAG(Retrieval-Augmented Generation)** 는 외부 자료를 검색하여 답변 생성에 활용하는 기술로, 환각을 줄이는 데 도움을 줄 수 있지만 완전히 제거하지는 못한다.

## 2장. 생성형 AI의 동작 원리

### 1. 토큰(Token)과 토큰화(Tokenization)

토큰은 LLM이 텍스트를 처리하는 기본 단위이다.

**토큰화**는 입력된 문장을 작은 단위로 나누는 과정이다.

```text
입력 문장:
나는 머신러닝을 공부한다.

토큰화 예시:
나는 | 머신 | 러닝 | 을 | 공부 | 한다 | .
```

실제 토큰은 모델의 토크나이저에 따라 다르게 분리될 수 있으며, 공백이나 문장부호도 토큰화에 영향을 준다.

### 2. 임베딩(Embedding)

임베딩은 토큰이나 데이터를 숫자 벡터로 표현하는 과정이다.

- 텍스트를 컴퓨터가 처리할 수 있는 벡터로 변환한다.
- 학습된 벡터 공간에서 의미나 사용 맥락이 유사한 표현이 가까운 위치에 나타날 수 있다.
- 검색, 추천, 분류 등 다양한 AI 기술에 활용된다.

**비유:** 임베딩은 언어의 의미를 표현하는 지도와 비슷하다.

### 3. 다음 토큰 예측(Next Token Prediction)

LLM은 앞에 주어진 문맥을 바탕으로 다음 토큰의 확률을 계산하고, 토큰을 선택하는 과정을 반복한다.

```text
① 입력 토큰 처리
       ↓
② 신경망(Transformer) 연산
       ↓
③ 다음 토큰 확률 계산
       ↓
④ 토큰 선택 및 출력
       ↓
⑤ 문맥과 KV 캐시 갱신
       ↓
다음 토큰 예측 반복
       ↓
종료 조건에 도달하면 종료
```

이 과정을 추론(Inference)이라고 한다.

**주의할 점**

- 추론 과정에서 모델의 가중치를 매번 학습하는 것은 아니다.
- 생성된 토큰이 문맥에 추가되고, KV 캐시 등의 계산 정보가 갱신된다.
- 메모리 부족은 처리 실패의 원인이 될 수 있지만, 응답 중단이 항상 저장 공간 부족 때문인 것은 아니다.

### 4. Temperature(온도)

Temperature는 다음 토큰을 선택할 때 확률 분포를 조절하는 설정이다.

| 온도 범위 | 특징 |
|---|---|
| 0.0~0.3 | 상대적으로 일관되고 결정적인 출력 |
| 0.4~0.7 | 일관성과 다양성의 균형 |
| 0.7~1.0 | 상대적으로 다양한 표현과 답변 |

※ 위 범위는 이해를 돕기 위한 일반적인 예시이며, 실제 동작은 모델과 API 설정에 따라 달라진다.

### 5. Context Window(컨텍스트 윈도우)

컨텍스트 윈도우는 모델이 한 번의 처리 과정에서 참고할 수 있는 토큰 범위이다.

**AI의 작업 책상**이라고 비유할 수 있다.

- 대화 내용과 문서 등의 정보를 문맥으로 활용한다.
- 모델마다 처리할 수 있는 컨텍스트 길이가 다르다.
- 문맥이 길어질수록 필요한 정보를 효율적으로 구성하는 것이 중요해진다.

### 6. Prompt Engineering과 Context Engineering

**Prompt Engineering**
- AI에 전달할 질문과 지시문을 효과적으로 작성하는 기술

**Context Engineering**
- AI가 작업에 필요한 정보, 문서, 대화 이력, 도구 결과 등을 적절하게 제공받도록 문맥을 설계하는 기술

**2장 핵심 키워드**

`Tokenization` · `Embedding` · `Inference` · `Next Token Prediction` · `Temperature` · `Context Window`

## 3장. 머신러닝의 학습 방식

### 1. 머신러닝의 주요 분류

머신러닝의 대표적인 학습 방식은 세 가지이다.

| 구분 | 설명 | 예시 |
|---|---|---|
| 지도학습 | 정답 레이블이 있는 데이터를 이용해 학습 | 스팸 메일 분류 |
| 비지도학습 | 정답 레이블 없이 데이터의 구조와 패턴을 학습 | 고객 군집 분석 |
| 강화학습 | 행동에 따른 보상을 바탕으로 학습 | 게임 AI |

### 2. 지도학습(Supervised Learning)

지도학습은 입력 데이터와 정답을 함께 제공하여 학습하는 방식이다.

**Training Data(훈련 데이터)**

모델을 학습시키기 위해 사용하는 데이터의 집합이다.

**Label(레이블)**

모델이 예측해야 하는 정답 또는 목표값이다.

| 이메일 내용 | 레이블 |
|---|---|
| 당첨을 축하합니다! | 스팸 |
| 내일 회의가 있습니다. | 정상 |
| 지금 대출을 신청하세요. | 스팸 |

모델은 데이터와 레이블의 관계를 학습하여 새로운 데이터를 예측한다.

### 3. 비지도학습(Unsupervised Learning)

정답 레이블을 제공하지 않고 데이터에 존재하는 패턴이나 구조를 찾는 학습 방식이다.

대표적인 활용 사례는 다음과 같다.

- 비슷한 고객끼리 그룹화
- 데이터의 군집 분석
- 이상치 탐지

### 4. 강화학습(Reinforcement Learning)

에이전트가 환경과 상호작용하면서 보상을 최대화하는 행동을 학습하는 방식이다.

```text
에이전트 → 행동 선택
               ↓
             환경
               ↓
       보상 및 다음 상태
               ↓
          학습 및 반복
```

보상은 양수 또는 음수일 수 있으며, 에이전트는 장기적인 누적 보상을 높이는 방향으로 학습한다.

**3장 핵심 키워드**

`Supervised Learning` · `Unsupervised Learning` · `Reinforcement Learning` · `Training Data` · `Label`

## 4장. Python 머신러닝 데이터 분석 실습 (오후 실습)

### 9. 평균값과 중앙값 산출

데이터의 대표적인 값을 확인하기 위해 평균값(Mean)과 중앙값(Median)을 계산한다.

```python
print("평균:", round(df["age"].mean(), 2))
print("중앙값:", round(df["age"].median(), 2))
```

- `mean()` : 데이터의 평균값
- `median()` : 데이터를 크기순으로 정렬했을 때 가운데 위치한 값
- `round(값, 2)` : 소수점 둘째 자리까지 반올림

평균은 극단적인 값의 영향을 받기 쉽지만, 중앙값은 상대적으로 영향을 덜 받는다.

### 10. 평균값을 이용한 결측치 처리

`fillna()`는 결측치(NaN)를 지정한 값으로 채우는 메서드이다.

```python
mean_age = df["age"].mean()

df.loc[:, "age"] = df["age"].fillna(mean_age)
```

**코드 설명**

- `df["age"].mean()` : 나이의 평균값 계산
- `fillna(mean_age)` : 나이가 비어 있는 부분을 평균값으로 채우기
- `df.loc[:, "age"]` : 모든 행의 `age` 컬럼 선택

결측치 처리 후 확인한다.

```python
print(df["age"].isnull().sum())
```

결측치가 모두 채워졌다면 결과는 `0`이다.

기존에 저장한 `empty_age` 조건을 사용하면 원래 나이가 비어 있었던 승객을 다시 확인할 수 있다.

```python
df.loc[empty_age, ["sex", "age", "class"]].head()
```

### 11. 최빈값을 이용한 결측치 처리

최빈값(Mode)은 데이터에서 가장 자주 등장하는 값이다.

이번에는 승객의 탑승 항구인 `embark_town` 컬럼을 확인한다.

```python
df["embark_town"].value_counts(dropna=False)
```

- `value_counts()` : 값별 등장 횟수 확인
- `dropna=False` : 결측치도 개수에 포함

**최빈값 추출**

```python
mode_town = df["embark_town"].mode()[0]

print("최빈값:", mode_town)
```

`mode()`는 최빈값을 Series로 반환하므로 `[0]`을 사용하여 첫 번째 최빈값을 가져온다.

**결측치 채우기**

```python
df.loc[:, "embark_town"] = df["embark_town"].fillna(mode_town)

df["embark_town"].value_counts(dropna=False)
```

수치형 데이터는 평균이나 중앙값을, 범주형 데이터는 최빈값을 결측치 대체 방법으로 고려할 수 있다. 단, 데이터의 특성에 따라 적절한 방법을 선택해야 한다.

### 12. 범주형 데이터(Category) 결측치 처리

타이타닉 데이터의 `deck` 컬럼은 객실 갑판 정보를 나타내는 범주형 데이터이다.

**기존 범주 확인**

```python
print(df["deck"].cat.categories.to_list())
```

기존 범주에는 `A`, `B`, `C`, `D`, `E`, `F`, `G` 등이 존재한다.

**새로운 범주 추가 및 결측치 처리**

```python
df["deck"] = df["deck"].cat.add_categories(["Unknown"]).fillna("Unknown")
```

이 코드는 다음 순서로 실행된다.

1. `add_categories(["Unknown"])` : 새로운 범주 등록
2. `fillna("Unknown")` : 결측치를 Unknown으로 변경

**결과 확인**

```python
print(df["deck"].cat.categories.to_list())
print(df["deck"].value_counts())
```

**실습 중 발생한 오류**

```python
df["deck"] = df["deck"].fillna("Unknown")
```

오류 메시지:

```text
TypeError: Cannot setitem on a Categorical
with a new category (Unknown),
set the categories first
```

**오류 원인:** `category` 자료형은 등록되지 않은 범주를 바로 입력할 수 없기 때문이다.

따라서 `Unknown`을 먼저 범주에 추가해야 한다.

주피터 노트북에서 셀을 여러 번 실행할 경우 중복 추가 오류를 방지하려면 다음처럼 작성할 수 있다.

```python
if "Unknown" not in df["deck"].cat.categories:
    df["deck"] = df["deck"].cat.add_categories(["Unknown"])

df["deck"] = df["deck"].fillna("Unknown")
```

### 14. 이상치(Outlier) 확인

이상치는 다른 데이터와 비교했을 때 지나치게 크거나 작은 값을 의미한다.

이번 실습에서는 승선 요금인 `fare` 컬럼을 활용한다.

**사분위수 확인**

```python
print(df["fare"].quantile([0.25, 0.5, 0.75]))

df["fare"].describe()[["25%", "50%", "75%"]]
```

| 구분 | 의미 |
|---|---|
| Q1 (25%) | 제1사분위수 |
| Q2 (50%) | 제2사분위수, 중앙값 |
| Q3 (75%) | 제3사분위수 |
| IQR | Q3 - Q1 |

**IQR을 이용한 이상치 기준 계산**

```python
q1 = df["fare"].quantile(0.25)
q3 = df["fare"].quantile(0.75)

iqr = q3 - q1

upper = q3 + 1.5 * iqr

print(f"Q1={q1:.2f}, Q3={q3:.2f} IQR={iqr:.2f} UPPER={upper:.2f}")

print("이상 승선요금:", (df["fare"] > upper).sum(), "명")
```

상한 기준:

\[
Upper = Q3 + 1.5 \times IQR
\]

일반적인 IQR 방법에서는 하한도 함께 사용한다.

\[
Lower = Q1 - 1.5 \times IQR
\]

이 범위를 벗어나는 값은 이상치 후보로 판단할 수 있다.

### 15. 특정 승선 요금 데이터 제거

실습에서는 승선 요금이 512 이상인 데이터를 제외했다.

```python
before = len(df)

df = df[df["fare"] < 512].copy()

print(before, "=>", len(df))
```

- `len(df)` : 데이터의 전체 행 개수
- `df["fare"] < 512` : 승선 요금이 512 미만인 행 선택
- `.copy()` : 선택한 데이터의 복사본 생성

여기서 `512`는 실습에서 사용한 기준값이며, 앞서 계산한 IQR 상한값과 동일한 기준은 아니다.

실제 분석에서는 이상치를 제거하기 전에 해당 값이 오류인지, 정상적으로 발생할 수 있는 값인지 확인해야 한다.

### 16. 중복 데이터 확인

```python
print("중복 행:", df.duplicated().sum(), "개")
```

- `duplicated()` : 이전 행과 모든 컬럼 값이 동일한 행을 중복으로 표시
- `sum()` : 중복 행의 개수 계산

**중복 데이터 조회**

```python
df[df.duplicated(keep=False)].sort_values(["fare", "age"]).head(5)
```

- `keep=False` : 중복된 모든 행을 표시
- `sort_values()` : 지정한 컬럼을 기준으로 정렬
- `head(5)` : 상위 5개 행 출력

단, 모든 컬럼 값이 같다고 해서 반드시 잘못된 중복 데이터는 아니므로 삭제 전 확인이 필요하다.

### 17. Matplotlib을 이용한 데이터 시각화

데이터의 분포를 확인하기 위해 Matplotlib 라이브러리를 사용한다.

**운영체제별 한글 폰트 설정**

```python
import platform
import matplotlib.pyplot as plt

os_name = platform.system()

if os_name == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"

elif os_name == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"
```

Windows에서는 `Malgun Gothic`, macOS에서는 `AppleGothic` 폰트를 설정한다.

**나이 분포 히스토그램**

```python
fig, ax = plt.subplots(figsize=(6, 4))

ax.hist(df["age"], bins=20, color="skyblue", edgecolor="black")

ax.set_title("나이분포")
ax.set_xlabel("나이(세)")
ax.set_ylabel("승객 수")

plt.show()
```

- `plt.subplots()` : 그래프를 그릴 Figure와 Axes 생성
- `figsize=(6, 4)` : 그래프 크기 지정
- `hist()` : 히스토그램 생성
- `bins=20` : 데이터를 20개 구간으로 나누기
- `set_title()` : 그래프 제목 설정
- `set_xlabel()` : X축 이름 설정
- `set_ylabel()` : Y축 이름 설정
- `plt.show()` : 그래프 출력

히스토그램을 통해 승객의 나이가 어떤 구간에 많이 분포하는지 확인할 수 있다.
