### WHERE 조건식 사용하기
```sh
SELECT * FROM courses WHERE course_id IN (1, 5, 10);
SELECT * FROM members WHERE name LIKE '이%';
# 저장된 데이터 안에 특정 조건에 부합하는 데이터를 추출하고 싶으면 WHERE를 사용하면 된다.
SELECT * FROM pices WHERE price >= 10000;
# 이렇게 강좌 아이디가 1,5,10 번인 데이터 추출, 이씨 추출, 10000원 이상인거 추출할 수 있다.
```

### BETWEEN 사용
```sh
- BETWEEN AND는  어디에서 어디 사이 라는 뜻으로 
SELECT * FROM members WHERE birth_year BETWEEN 1995 AND 2000;

- 출생이 1995에서 2000인 데이터를 추출한다.
```

### COUNT() 사용
```sh
- 조건에 맞는 데이터를 추출하여 개수를 세준다.
SELECT COUNT(*) FROM members WHERE region = '마포구';
SELECT COUNT(*) FROM members WHERE email IS NULL;

이때, 그 데이터가 어떤 분류인지 본인이 설정할 수 있는데 그때, AS 키워드를 사용한다.
SELECT COUNT(*) AS "E-mail 미기재" FROM members WHERE email IS NULL;
- AS 키워드는 칼럼의 제목과 같은 것이다. 튜플들이 나열되어있을 때, 열들의 제목이라고 생각하면 된다.
```
