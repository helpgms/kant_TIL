### 도커는 무엇일까?

- 개발자들이 본인 PC에 맞게 환경 셋팅이 끝났는데 본인이 했던 개발 환경을 그대로 올릴 수 있게 해주는 게 도커이다.
- 남들이 본인이 한 프로젝트들을 할때, 오류가 날 수 있다. 하지만, 도커를 통해 본인의 환경 셋팅을 컨테이너화 해서 올리면 남들도 본인이 쓴 환경처럼 사용할 수 있어 오류가 나지 않는다.

### 도커 데스크탑 사용방벙

- images => 닌텐도 스위치 칩이라 생각하면 됨, 칩을 바꾸면 그 게임이 실행되듯.
- 칩만 가지고는 게임이 실행이 안된다. 여기서 게임이 바로 컨테이너이다. 본체는 꺼도 컨테이너는 켜놓을 수 있다.
- 오피셜 마크가 있는 것으로 하자

### 도커 터미널
(순서대로 생성)
- 이미지 받아오기 : **docker pull 이미지 이름** (생성)
- 받아온 이미지 컨테이너에 넣기 : **docker run 이미지 이름** (실행)
여기서부터 본격적인 내용
- 목록 확인(프로세스 확인) : **docker ps** (진행 중)
- 정지된 목록 확인 : **docker ps -a** (종료된)
- 도커 데스크탑 이미지 목록 보기 : **docker image ls, docker images** (두개임)
- 컨테이너 삭제 : **docker rm 아이디 -f (강제 삭제), docker rm 아이디**
- 이미지 삭제 : **docker rmi 아이디** 
- 이미지를 터미널화해서 들어가겠다 : **docker run -it --name 컨테이너 이름(내가 지정) ubuntu:24.04(기존 이미지 명) 어떤 쉘로 사용할건지(bash)**
 => 우분투 안으로 들어가게 됨
- 이때, 만약 나갔다가 그 컨테이너를 다시 시작하고 싶으면 : **docker start 컨테이너 명** , 후 **docker exec -it 컨테이너 명 사용 쉘** 하면 들어가진다. 이때, it는 상호작용을 의미한다. -> 이때, 한번에 들어가는 방법이 존재한다. **docker start -ai 컨테이너 명** 하면 된다
- 멈추는 방법 : **docker stop 컨테이너 명**
- 들어가서 확인해보자 : **cat os-release**
- 파일 만들기 : **echo "# Hello Docker" > README.md**
- 우리가 터미널에서 했던 것들을 docker 데스크탑에서도 할 수 있다. Exec 안에 들어가면 터미널이 하나 나오는데 거기서도 기능이 가능하다.
- 지금 현 상황은 우분투 안에 아무것도 안들어가 있는 상태이다. 이때, apt update를 하고, 안에서 필요한 작업들을 수행한다.
- 웹서버를 만들어보자 : **docker run -d --name 컨테이너 명 -p(포트번호 옵션) 외부 포트 번호: 내부 포트 번호 실행할 이미지**
- 터미널에서 웹서버를 받아와보자 : **curl 웹서버 주소**
- 포트번호가 잘 떠있는 지 확인해보자 : **netstat -ano | grep :포트번호**
- 도커 환경에서 프론트엔드 구현해보자 : **echo "<h1> ~~~~ </h1>" > index.html(이거는 확인해봐야함)**
- 프론트엔드 작업을 할때는 계속 모니터링을 해야하는데 그때 쓰는 기능: **docker logs 명**
- 로그 확인 : **docker logs -f 명**
- sql 들어가기 : **docker run -d --name my-sql -e MYSQL_ROOT_PASSWORD=1234 -p 3306:3306 mysql:8.4**
- 이제 들어가려면 : **docker exec -it my-sql mysql -uroot -p** 이 명령어를 실행하면 다시 들어가진다. 이때 비번을 치고 들어가게 된다
- 만약 비번을 치다가 잘못쳤을때, ctrl + u 를 누르면 다 지워진다.
- SQL은 항상 퀄을 작성할때, 전부 대문자로 작성.
- SQL을 터미널로 넘어가서 컨테이너를 삭제하면 안에 있던 데이터베이스들이 사라진다. 이를 확인하기 위해 : **SHOW DATABASES;하면 데이터베이스들이 보인다.
- postgres에 들어갈때는 : docker exec -it my-pg psql -U postgres 이렇게.. 나갈때는 \q로 끝
