## 1장. 머신러닝의 학습 원리

### 1. 머신러닝에서 학습이란?

머신러닝은 개발자가 결과를 계산하는 규칙을 직접 작성하는 것이 아니라, 컴퓨터가 주어진 데이터를 기반으로 적절한 규칙과 파라미터를 찾아내는 기술이다.

선형 회귀 모델에서 입력 특성이 3개라면 다음과 같은 식으로 표현할 수 있다.

```text
y_hat = w1*x1 + w2*x2 + w3*x3 + b
```

| 구분 | 설명 |
|---|---|
| x1, x2, x3 | 입력 데이터(Feature) |
| w1, w2, w3 | 가중치(Weight) |
| b | 편향(Bias) |
| y | 실제 정답 |
| y_hat | 모델의 예측값 |

개발자는 입력 데이터와 정답을 제공하고, 모델은 학습을 통해 적절한 가중치와 편향을 찾아낸다.

### 2. 일반 프로그래밍과 머신러닝의 차이

| 구분 | 일반 프로그래밍 | 머신러닝 |
|---|---|---|
| 규칙 | 개발자가 직접 작성 | 데이터로부터 학습 |
| 입력 | 데이터 | 데이터와 정답(지도학습) |
| 결과 | 작성된 규칙에 따른 출력 | 학습된 모델을 통한 예측 |

일반 프로그래밍에서는 개발자가 계산 공식을 직접 작성한다.

```python
price = area * 450 + 5000
```

머신러닝에서는 데이터를 제공하고 모델이 적절한 가중치와 편향을 찾도록 한다.

```python
model.fit(X, y)
```

### 3. 머신러닝의 학습 과정

```text
입력 데이터 제공
       ↓
모델의 결과 예측
       ↓
실제값과 예측값 비교
       ↓
손실 함수 계산
       ↓
가중치 및 편향 업데이트
       ↓
반복 학습
```

이러한 학습 방식은 선형 회귀뿐만 아니라 딥러닝과 LLM에서도 활용되는 기본적인 원리이다.

## 2장. 경사하강법 (Gradient Descent)

### 1. 경사하강법이란?

경사하강법은 손실 함수의 기울기를 계산하고, 손실이 감소하는 방향으로 모델의 파라미터를 반복적으로 업데이트하는 최적화 알고리즘이다.

모델의 예측값과 실제값 사이의 오차를 줄이는 것을 목표로 한다.

### 2. 손실 함수 (Loss Function)

모델의 예측값과 실제값이 얼마나 차이가 나는지를 수치로 나타내는 함수이다.

회귀 모델에서는 대표적으로 MSE(Mean Squared Error)를 사용한다.

```text
MSE = (실제값 - 예측값)²의 평균
```

손실 함수의 값이 작을수록 해당 데이터에 대한 예측 오차가 작다는 의미이다.

### 3. 경사하강법의 가중치 업데이트

```text
새로운 가중치 = 기존 가중치 - 학습률 × 손실 함수의 기울기
```

기울기가 양수라면 가중치를 감소시키고, 음수라면 가중치를 증가시키는 방향으로 업데이트한다.

이 과정을 반복하면서 손실 함수가 작아지는 지점을 찾아간다.

### 4. 경사하강법의 종류

| 종류 | 설명 |
|---|---|
| Batch Gradient Descent | 전체 학습 데이터를 사용하여 한 번 업데이트 |
| Stochastic Gradient Descent | 개별 학습 데이터를 사용하여 업데이트 |
| Mini-Batch Gradient Descent | 일정한 크기의 데이터 묶음을 사용하여 업데이트 |

SGD는 데이터를 하나씩 사용하여 파라미터를 업데이트하므로 학습 과정에서 손실값이 불규칙하게 변할 수 있다.

## 3장. 학습률 (Learning Rate)

### 1. 학습률이란?

학습률은 경사하강법에서 가중치를 한 번 업데이트할 때 이동하는 정도를 결정하는 값이다.

```python
eta0 = 0.01
```

| 학습률 | 특징 |
|---|---|
| 너무 작음 | 학습 속도가 느려질 수 있음 |
| 적절함 | 안정적으로 손실이 감소할 수 있음 |
| 너무 큼 | 최적점을 지나치거나 손실이 발산할 수 있음 |

학습률이 크다고 해서 반드시 학습 성능이 좋아지는 것은 아니다.

### 2. 파라미터와 하이퍼파라미터

| 구분 | 설명 | 예시 |
|---|---|---|
| Parameter | 모델이 학습을 통해 결정하는 값 | 가중치, 편향 |
| Hyperparameter | 개발자가 학습 전에 설정하는 값 | 학습률, 최대 반복 횟수, K값 |

가중치와 편향은 모델이 직접 학습하지만, 학습률과 같은 하이퍼파라미터는 개발자가 설정한다.

## 4장. 데이터 표준화 (Standardization)

### 1. 표준화란?

서로 다른 범위와 단위를 가진 데이터의 평균과 표준편차를 이용하여 데이터의 스케일을 조정하는 전처리 방법이다.

```text
z = (x - 평균) / 표준편차
```

일반적으로 학습 데이터의 각 특성을 평균 0, 분산 1에 가까운 형태로 변환한다.

### 2. 표준화가 필요한 이유

입력 특성마다 데이터의 범위가 크게 다르면 경사하강법의 학습 과정이 불안정하거나 느려질 수 있다.

예를 들어 다음과 같은 데이터가 있다고 가정한다.

| 특성 | 값의 범위 예시 |
|---|---|
| 방 개수 | 1 ~ 5 |
| 면적 | 20 ~ 150 |
| 연간 소득 | 20,000 ~ 100,000 |

각 특성의 스케일이 다르므로 표준화를 통해 데이터 범위를 조정할 수 있다.

### 3. StandardScaler 사용 방법

다음은 표준화 과정에 대한 복습 예시이다.

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

| 메서드 | 설명 |
|---|---|
| fit() | 평균과 표준편차 계산 |
| transform() | 계산된 평균과 표준편차를 사용하여 변환 |
| fit_transform() | 평균과 표준편차 계산 및 변환 |

테스트 데이터에서는 fit_transform()을 사용하지 않고 transform()만 사용해야 한다.

학습 데이터에서 계산한 기준으로 테스트 데이터를 변환하여 데이터 누수(Data Leakage)를 방지할 수 있다.

## 5장. SGDRegressor 모델 학습

### 1. SGDRegressor란?

Scikit-learn에서 제공하는 확률적 경사하강법 기반의 선형 회귀 모델이다.

```python
from sklearn.linear_model import SGDRegressor
```

### 2. 모델 생성

```python
sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=3000,
    random_state=42
)
```

| 매개변수 | 설명 |
|---|---|
| loss | 손실 함수 설정 |
| squared_error | 제곱 오차 기반 손실 함수 |
| learning_rate | 학습률 조정 방식 |
| constant | 일정한 학습률 유지 |
| eta0 | 초기 학습률 |
| max_iter | 최대 Epoch 횟수 |
| random_state | 난수 생성의 재현성을 위한 설정 |

모델 객체를 생성하는 단계에서는 학습이 이루어지지 않는다.

어떤 방식으로 학습할 것인지 설정하는 단계이다.

### 3. 모델 학습

```python
# 표준화된 학습 데이터(70%)로 모델 학습
sgd.fit(X_train_scaled, y_train)
```

fit()을 실행하면 모델이 입력 데이터와 정답 데이터를 기반으로 가중치와 편향을 학습한다.

### 4. 모델 예측

```python
# 표준화된 테스트 데이터(30%)로 모델 예측
sgd_pred = sgd.predict(X_test_scaled)
```

predict()는 학습된 가중치와 편향을 이용하여 새로운 데이터의 결과를 예측한다.

predict()를 실행한다고 해서 모델의 가중치가 업데이트되는 것은 아니다.

### 5. 모델 성능 평가

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

print(f"MAE: {mean_absolute_error(y_test, sgd_pred):.4f}")
print(f"MSE: {mean_squared_error(y_test, sgd_pred):.4f}")
print(f"R2: {r2_score(y_test, sgd_pred):.4f}")
```

| 평가 지표 | 설명 |
|---|---|
| MAE | 평균 절대 오차 |
| MSE | 평균 제곱 오차 |
| R² | 모델이 데이터의 변동을 설명하는 정도 |

MAE와 MSE는 작을수록 좋으며, R²는 일반적으로 1에 가까울수록 좋다.

## 6장. Epoch와 반복 학습

### 1. Epoch란?

전체 학습 데이터를 한 번 학습하는 과정을 1 Epoch라고 한다.

```text
전체 학습 데이터 1회 학습 = 1 Epoch
전체 학습 데이터 500회 학습 = 500 Epoch
```

Epoch가 증가하면 모델이 데이터를 반복적으로 학습하게 된다.

다만 반복 횟수가 많다고 해서 반드시 새로운 데이터에 대한 예측 성능이 좋아지는 것은 아니다.

### 2. fit()과 partial_fit()의 차이

| 구분 | fit() | partial_fit() |
|---|---|---|
| 학습 방식 | 설정된 조건에 따라 모델 학습 | 기존 학습 상태에서 추가 학습 |
| 반복 횟수 | max_iter 및 종료 조건에 따라 결정 | SGDRegressor 기준 호출당 1 Epoch |
| 기존 가중치 | 기본적으로 새롭게 학습 | 기존 가중치를 유지하며 업데이트 |
| 활용 | 일반적인 모델 학습 | 점진적 학습 및 학습 과정 관찰 |

### 3. 500 Epoch 학습 실습

```python
sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    random_state=42
)

history = []

# 500 Epoch 학습
for epoch in range(500):

    # 1 Epoch 학습
    sgd.partial_fit(X_train_scaled, y_train)

    # 학습 데이터 예측
    pred = sgd.predict(X_train_scaled)

    # 학습 결과 기록
    history.append({
        "epoch": epoch + 1,
        "w1": sgd.coef_[0],
        "w2": sgd.coef_[1],
        "w3": sgd.coef_[2],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y_train, pred)
    })

# 반복문 종료 후 DataFrame 생성
history_df = pd.DataFrame(history)

history_df.round(2)
```

### 4. 학습 과정 기록

| 컬럼 | 설명 |
|---|---|
| epoch | 현재 학습 횟수 |
| w1 | 첫 번째 입력 특성의 가중치 |
| w2 | 두 번째 입력 특성의 가중치 |
| w3 | 세 번째 입력 특성의 가중치 |
| bias | 모델의 편향 |
| mse | 해당 Epoch의 학습 데이터 평균 제곱 오차 |

history.append()를 사용하여 각 Epoch에서 모델의 가중치, 편향, 손실값을 딕셔너리 형태로 저장한다.

```python
sgd.coef_
```

모델이 학습한 각 입력 특성의 가중치를 반환한다.

```python
sgd.intercept_
```

모델이 학습한 편향을 반환한다.

### 5. 학습 결과 확인

```python
history_df.head(10).round(2)
```

초반 10 Epoch의 학습 결과를 확인한다.

```python
history_df.tail(10).round(2)
```

마지막 10 Epoch의 학습 결과를 확인한다.

```python
history_df.shape
```

예상 결과:

```text
(500, 6)
```

500개의 학습 기록과 6개의 컬럼으로 구성된다.

## 7장. 학습(Training)과 추론(Inference)

### 1. 학습

```python
sgd.partial_fit(X_train_scaled, y_train)
```

데이터와 정답을 기반으로 모델의 가중치와 편향을 업데이트하는 과정이다.

### 2. 추론

```python
sgd.predict(X_test_scaled)
```

이미 학습된 모델을 사용하여 새로운 입력 데이터의 결과를 예측하는 과정이다.

### 3. 학습과 추론 비교

| 구분 | Training | Inference |
|---|---|---|
| 목적 | 모델의 파라미터 학습 | 결과 예측 |
| 가중치 변경 | O | X |
| 정답 데이터 필요 여부 | 지도학습에서는 필요 | 필요하지 않음 |
| 대표 메서드 | fit(), partial_fit() | predict() |

이러한 개념은 LLM의 학습과 추론에도 연결된다.

LLM 역시 학습 과정에서 파라미터를 업데이트하고, 일반적인 추론 과정에서는 학습된 파라미터를 활용하여 결과를 생성한다.

## 8장. KNN (K-Nearest Neighbors)

### 1. KNN이란?

KNN은 새로운 데이터와 가장 가까운 K개의 기존 데이터를 찾아 분류하거나 값을 예측하는 머신러닝 알고리즘이다.

K-Nearest Neighbors는 K개의 가장 가까운 이웃이라는 의미이다.

대표적인 지도학습 알고리즘으로 분류와 회귀 모두에 사용할 수 있다.

### 2. KNN의 동작 원리

```text
새로운 데이터 입력
        ↓
기존 데이터와의 거리 계산
        ↓
가장 가까운 K개의 데이터 선택
        ↓
분류: 이웃의 클래스 투표
회귀: 이웃의 값 평균 등
        ↓
최종 결과 예측
```

예를 들어 K=5인 분류 모델에서 가장 가까운 데이터가 다음과 같다고 가정한다.

```text
A, A, B, A, B
```

A는 3개, B는 2개이므로 동일한 투표 가중치를 사용하는 KNN에서는 A로 분류한다.

### 3. K값의 의미

K는 예측할 때 참고할 주변 데이터의 개수이다.

| K값 | 특징 |
|---|---|
| K=1 | 가장 가까운 데이터 하나만 참고 |
| K=3 | 가장 가까운 데이터 3개 참고 |
| K=5 | 가장 가까운 데이터 5개 참고 |

K값이 너무 작으면 이상치와 노이즈에 민감할 수 있다.

반대로 K값이 너무 크면 데이터의 세부적인 특징을 반영하기 어려울 수 있다.

### 4. 유클리드 거리 (Euclidean Distance)

KNN에서 대표적으로 사용하는 거리 계산 방법이다.

두 점 사이의 직선거리를 계산한다.

```text
A = (x1, y1)
B = (x2, y2)

거리 = √((x2-x1)² + (y2-y1)²)
```

예를 들어 A=(1, 2), B=(4, 6)이라면 다음과 같다.

```text
거리 = √((4-1)² + (6-2)²)
     = √(9 + 16)
     = 5
```

KNN은 이러한 거리 계산을 통해 새로운 데이터와 유사한 데이터를 찾는다.

### 5. SGD와 KNN의 차이

| 구분 | SGD 기반 선형 회귀 | KNN |
|---|---|---|
| 학습 방식 | 가중치와 편향 업데이트 | 학습 데이터 저장 및 검색 구조 준비 |
| 예측 방식 | 학습된 회귀식 활용 | 가까운 데이터 참고 |
| 학습률 | 사용 | 사용하지 않음 |
| Epoch | 사용 | 일반적으로 사용하지 않음 |
| 주요 하이퍼파라미터 | 학습률, 반복 횟수 | K값, 거리 계산 방식 |
| 특징 | 파라미터 기반 학습 | 거리 기반 예측 |

KNN은 SGD처럼 반복적으로 가중치를 업데이트하지 않는다.

이러한 특징 때문에 게으른 학습(Lazy Learning)이라고도 한다.

## 11장. 픽셀(Pixel)과 이미지의 수치 표현

### 1. 컴퓨터는 이미지를 어떻게 이해하는가?

컴퓨터는 이미지를 사람처럼 직접 인식하는 것이 아니라 숫자로 구성된 데이터로 처리한다.

흑백 이미지는 각 픽셀의 밝기를 하나의 숫자로 표현할 수 있다.

Olivetti Faces 데이터셋에서는 픽셀의 밝기가 0부터 1 사이의 값으로 표현되어 있다.

```python

print("가장 밝은 값:", faces.images.max())
```

실제 실습 결과:

```text
가장 어두운 값: 0.0
가장 밝은 값: 1.0
```

| 픽셀값 | 의미 |
|---:|---|
| 0.0 | 검은색 |
| 0.25 | 어두운 회색 |
| 0.5 | 중간 회색 |
| 0.75 | 밝은 회색 |
| 1.0 | 흰색 |

### 2. 이미지의 일부 영역 추출

```python
corner = faces.images[0][20:28, 20:28]
```

첫 번째 얼굴 이미지에서 특정 행과 열의 범위를 선택한다.

```text
faces.images[0][20:28, 20:28]
                  │      │
                  │      └── 열 인덱스 범위
                  └───────── 행 인덱스 범위
```

Python의 슬라이싱은 시작 인덱스를 포함하고 종료 인덱스를 포함하지 않는다.

따라서 20번부터 27번까지 총 8개의 행과 8개의 열을 선택한다.

```text
기존 이미지: 64 × 64 = 4,096개 픽셀
추출 이미지:  8 × 8 = 64개 픽셀
```

### 3. 픽셀값 직접 시각화

```python
fig, ax = plt.subplots(figsize=(5, 5))

ax.imshow(
    corner,
    cmap="grey",
    vmin=0,
    vmax=1
)

plt.axis("off")

for r in range(8):
    for c in range(8):

        # r번째 행, c번째 열
        v = corner[r, c]

        ax.text(c, r, f"{v:.1f}")

plt.show()
```

### 4. 이중 반복문 분석

```python
for r in range(8):
    for c in range(8):
```

바깥쪽 반복문은 행을 순회하고, 안쪽 반복문은 열을 순회한다.

총 8×8=64번 반복한다.

```python
v = corner[r, c]
```

해당 행과 열에 존재하는 픽셀의 밝기 값을 가져온다.

```python
ax.text(c, r, f"{v:.1f}")
```

이미지의 해당 위치에 픽셀값을 소수점 첫째 자리까지 표시한다.

배열에서는 행과 열 순서로 접근하지만, 그래프 좌표는 X축과 Y축 순서이므로 text()에서는 c, r 순서로 작성한다.

## 13장. 이미지 데이터와 KNN의 관계

### 1. 이미지를 입력 특성으로 변환

한 장의 얼굴 이미지는 64×64 크기의 2차원 배열이다.

일반적인 Scikit-learn의 KNN 모델은 하나의 샘플을 1차원 특성 벡터로 표현한 2차원 입력 데이터를 사용한다.

```text
64 × 64 이미지
       ↓
4,096개의 픽셀값
       ↓
하나의 입력 특성 벡터
```

Olivetti Faces 데이터셋은 이미 펼쳐진 이미지 데이터도 제공한다.

```python
X = faces.data
y = faces.target
```

데이터 구조:

```text
X.shape = (400, 4096)
y.shape = (400,)
```

400개의 이미지가 각각 4,096개의 입력 특성을 가지게 된다.

### 2. 이미지 분류의 원리

KNN을 이용하여 얼굴 이미지를 분류한다면 새로운 이미지와 기존 이미지 사이의 픽셀값 거리를 계산할 수 있다.

```text
새로운 얼굴 이미지 입력
        ↓
4,096개의 숫자 데이터로 표현
        ↓
기존 얼굴 이미지와 거리 계산
        ↓
가장 가까운 K개의 이미지 선택
        ↓
이웃 이미지의 사람 번호 확인
        ↓
사람 번호 예측
```

다만 단순히 픽셀값의 거리가 가깝다고 해서 반드시 같은 사람이라는 의미는 아니다.

표정, 조명, 얼굴 방향 등의 영향을 받을 수 있다.

이번 실습에서는 KNN 모델을 실제로 학습시키기 전 얼굴 이미지 데이터의 구조와 픽셀값을 확인하는 과정까지 진행하였다.

## 17장. 오늘의 느낀 점

오늘은 경사하강법을 이용하여 머신러닝 모델이 실제로 어떻게 학습하는지 공부하였다.

처음에는 라이브러리를 불러오고 정해진 코드를 작성하는 것이 실제로 컴퓨터가 학습하는 과정인지 궁금하였다.

하지만 fit()과 partial_fit()을 통해 모델이 가중치와 편향을 직접 계산하고 업데이트한다는 것을 이해하게 되었다.

특히 500 Epoch 동안 가중치와 편향, MSE를 기록하면서 모델의 학습 과정을 직접 확인할 수 있다는 점이 신기하였다.

오후에는 KNN 알고리즘과 얼굴 이미지 데이터셋을 공부하였다. 사람의 얼굴 사진도 결국 숫자로 구성된 배열이며, 하나의 이미지가 수천 개의 입력 특성으로 표현될 수 있다는 것을 알게 되었다.

또한 SGD와 KNN을 비교하면서 모든 머신러닝 알고리즘이 동일한 방식으로 학습하는 것은 아니라는 점을 이해하였다.

앞으로는 단순히 라이브러리와 메서드를 사용하는 것에 그치지 않고, 모델마다 어떤 방식으로 데이터를 학습하고 예측하는지 이해하면서 공부하고자 한다.
