### ORDER BY
```sh
- 쉽게 말하면 정렬이다.
- 정보들이 많을때, 튜플들을 정리해줘야하는데, 그거에 대해 기준을 어떤 것으로 할까? 와 같은 말이다.
ORDER BY birth_year, member_id;
-> 생년월일로 정렬하고, 같으면 member_id로 정렬해라 
```
---

### HAVING (조건) & GROUP BY
```sh
- 튜플들을 묶어서 추출하는 경우가 있는데 그때 조건절을 HAVING 키워드를 사용한다.
- 묶는 개념은 GROUP BY이고, 하기 전엔 WHERE 키워드을 사용한다.
```
```sh
HAVING COUNT(region) >= 5
```
```sh
-> region을 GROUP BY 한 뒤 조건을 하기 위해 HAVING 키워드를 사용했다.
```
---

### DISTINCT (중복 제거)
```sh
- 튜플들이 중복적으로 담겨지는 경향이 있는데, 그것을 방지하기 위함이다.
```

### JOIN
```sh
- JOIN은 테이블 안에 컬럼들을 원하는 컬럼만 뽑아서 다른 테이블과 같이 보고 싶을때, 사용한다.
- JOIN은 서로 다른 테이블에서 그들을 연결할 수 있는 공통 기준이 있으면 만들 수 있다.
```
```sh
SELECT m.name               AS 회원명,
       m.phone              AS 전화번호,
       c.course_name        AS 강좌명,
       e.enroll_month       AS 수강월
FROM enrollments e
JOIN courses c ON e.course_id = c.course_id
JOIN members m ON e.member_id = m.member_id
WHERE e.enroll_month = '2026-10' AND status = '취소'
ORDER BY m.name; 

-> enrollments라는 테이블에 courses 라는 테이블을 course_id를 기준으로 JOIN하겠다.
course_id 기준으로 보고 싶은 테이블을 보겠다라는 의미이다.
-> enrollments라는 테이블에 members 라는 테이블을 member_id를 기준으로 JOIN하겠다.
member_id 기준으로 보고 싶은 테이블을 보겠다라는 의미이다.
```

### SUB 쿼리
```sh
SELECT 
    course_name,
    fee,
    ROUND((SELECT AVG(fee) FROM courses),2)         AS 전체평균,
    fee - ROUND((SELECT AVG(fee) FROM courses),2)   AS 평균과차이
FROM courses;

-> courses 테이블에서 fee의 평균을 소수점 2에서 업해서 보겠다. 라는 서브 쿼리문이다.
```
```sh
SUB 쿼리는 하나의 sql문 안에 포함된 또 다른 sql문으로, 조회 결과를 바깥쪽 쿼리에서 활용하기 위함이다.
```
