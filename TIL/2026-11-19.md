## 2. PostgreSQL 연결 라이브러리 설치

Python에서 PostgreSQL 데이터베이스에 연결하기 위해 `psycopg` 라이브러리를 설치한다.

```bash
uv add "psycopg[binary]"
```

- `uv add` : Python 프로젝트에 필요한 패키지를 추가하는 명령어
- `psycopg` : Python에서 PostgreSQL에 연결하고 SQL을 실행할 수 있도록 지원하는 라이브러리
- `[binary]` : 필요한 바이너리 구성 요소를 함께 설치하는 옵션

---

## 3. PostgreSQL 데이터베이스 연결

`main.py`에 다음 코드를 작성한다.

```python
import psycopg

# DSN : Data Source Name
DSN = "host=localhost port=5432 dbname=sportscenter user=postgres password=1234"
```

### DSN이란?

DSN(Data Source Name)은 데이터베이스에 접속하기 위한 연결 정보를 의미한다.

| 항목 | 설명 |
|---|---|
| host | 데이터베이스 서버 주소 |
| port | PostgreSQL 연결 포트 |
| dbname | 연결할 데이터베이스 이름 |
| user | 데이터베이스 사용자 |
| password | 데이터베이스 비밀번호 |

### 연결 확인

```python
def main():
    with psycopg.connect(DSN) as conn:
        row = conn.execute(
            "SELECT current_database(), current_user"
        ).fetchone()

        print("연결 성공:", row)

if __name__ == "__main__":
    main()
```

**핵심 개념**

- `psycopg.connect(DSN)` : PostgreSQL 데이터베이스에 연결한다.
- `with ... as conn` : 연결을 관리하는 컨텍스트 매니저를 사용한다.
- `conn.execute()` : SQL문을 실행한다.
- `fetchone()` : 조회 결과에서 한 행을 가져온다.
- `current_database()` : 현재 연결된 데이터베이스 이름을 반환한다.
- `current_user` : 현재 데이터베이스 사용자 이름을 반환한다.

## 4. SQL 조회 결과 가져오기

### ① fetchone() : 한 행 조회

```python
row = conn.execute(
    "SELECT current_database(), current_user"
).fetchone()

print(row)
```

조회 결과 중 한 행을 가져오며, 기본적으로 튜플 형태로 반환한다.

### ② fetchall() : 여러 행 조회

```python
rows = conn.execute(
    "SELECT course_id, course_name, fee FROM courses LIMIT 5"
).fetchall()

print(rows)
```

- `SELECT` : 조회할 컬럼 지정
- `FROM courses` : 조회할 테이블 지정
- `LIMIT 5` : 최대 5개의 행 조회
- `fetchall()` : 조회 결과의 남은 모든 행을 리스트로 반환

### 전체 코드

```python
import psycopg

DSN = "host=localhost port=5432 dbname=sportscenter user=postgres password=1234"

def main():
    with psycopg.connect(DSN) as conn:
        row = conn.execute(
            "SELECT current_database(), current_user"
        ).fetchone()

        print("연결 성공:", row)

        rows = conn.execute(
            "SELECT course_id, course_name, fee FROM courses LIMIT 5"
        ).fetchall()

        print(rows)

if __name__ == "__main__":
    main()
```

## 5. dict_row를 이용한 딕셔너리 형태 조회

기본적으로 `psycopg`에서 데이터를 조회하면 튜플 형태로 반환된다.

하지만 `dict_row`를 사용하면 **컬럼 이름을 Key로 가지는 딕셔너리 형태**로 데이터를 가져올 수 있다.

### dict_row 가져오기

```python
from psycopg.rows import dict_row
```

### 사용 방법

```python
import psycopg
from psycopg.rows import dict_row

DSN = "host=localhost port=5432 dbname=sportscenter user=postgres password=1234"

def main():
    with psycopg.connect(DSN, row_factory=dict_row) as conn:
        rows = conn.execute(
            "SELECT course_id, course_name, fee FROM courses LIMIT 5"
        ).fetchall()

        for row in rows:
            print(row["course_name"], row["fee"])

if __name__ == "__main__":
    main()
```

### dict_row 사용 전후 비교

**기본 조회 (Tuple)**

```python
(1, "파이썬 기초", 50000)
```

```python
print(row[1])
```

**dict_row 사용 (Dictionary)**

```python
{
    "course_id": 1,
    "course_name": "파이썬 기초",
    "fee": 50000
}
```

```python
print(row["course_name"])
```

※ 위 데이터는 반환 형태를 설명하기 위한 예시이다.

### dict_row의 장점

- 컬럼 이름으로 데이터에 접근할 수 있다.
- 코드의 가독성이 높아진다.
- 컬럼 순서가 변경되어도 이름으로 접근할 수 있다.

## 6. 오늘 배운 내용 정리

| 명령어 및 함수 | 설명 |
|---|---|
| `git add -A` | Git 저장소의 모든 변경사항 스테이징 |
| `uv add "psycopg[binary]"` | PostgreSQL 연결 라이브러리 설치 |

| `conn.execute()` | SQL 실행 |

| `fetchall()` | 조회 결과에서 남은 모든 행 가져오기 |
| `dict_row` | 조회 결과를 딕셔너리 형태로 반환 |
| `row_factory` | 조회 결과의 반환 형태 지정 |
