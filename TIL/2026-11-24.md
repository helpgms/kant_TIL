## 1장. Pandas 데이터 전처리

### 1. 문자열 데이터 가공 (str)

문자열 데이터에서 특정 위치의 문자를 추출할 수 있다.

```python
df.loc[:, "embark_town"] = df["embark_town"].str[0]
```

| 기존 데이터 | 변환 후 |
|---|---|
| Southampton | S |
| Cherbourg | C |
| Queenstown | Q |

- `loc[:, "embark_town"]`: 모든 행의 embark_town 컬럼 선택
- `str`: Series의 문자열 관련 기능 사용
- `[0]`: 각 문자열의 첫 번째 문자 추출

기존 문자열을 간단한 형태로 변환할 수 있으며, 위 코드는 기존 컬럼을 덮어쓴다.

### 2. 결측치 처리 (ffill, bfill)

```python
test = df["deck"].ffill().bfill()

pd.DataFrame({
    "원본": df["deck"].value_counts(),
    "ffill, bfill 후": test.value_counts()
})
```

| 메서드 | 설명 |
|---|---|
| fillna() | 지정한 값으로 결측치 채우기 |
| ffill() | 앞에 있는 유효한 값으로 결측치 채우기 |
| bfill() | 뒤에 있는 유효한 값으로 결측치 채우기 |

**결측치 처리 예시**

| 원본 | ffill() | ffill().bfill() |
|---|---|---|
| NaN | NaN | A |
| A | A | A |
| NaN | A | A |
| B | B | B |
| NaN | B | B |

ffill()을 실행한 후에도 첫 부분에 결측치가 남을 수 있으므로 bfill()을 추가하여 처리할 수 있다.

단, 타이타닉의 갑판 정보처럼 각 행이 독립적인 데이터에서는 앞뒤 값을 이용한 결측치 처리가 적절하지 않을 수 있다.

### 3. value_counts()와 dropna

```python
df["deck"].value_counts(dropna=False)
```

- `value_counts()`: 각 값이 몇 개씩 존재하는지 계산
- `dropna=True`: 결측치를 제외하고 계산 (기본값)
- `dropna=False`: 결측치를 포함하여 계산

dropna는 특정 값을 지정하는 옵션이 아니라 결측치 포함 여부를 설정하는 Boolean 매개변수이다.

### 2. Boolean Mask (불리언 마스크)

조건식을 이용하여 각 데이터가 조건을 만족하는지 True 또는 False로 나타낼 수 있다.

```python

```

| x | 조건 결과 |
|---:|---|
| 5.2 | False |
| 0 | True |
| 3.5 | False |
| 0 | True |

True는 1, False는 0으로 계산할 수 있으므로 sum()을 사용하여 조건을 만족하는 데이터의 개수를 구할 수 있다.

```python
(df["x"] == 0).sum()
```

### 3. x, y, z 컬럼의 0 개수 확인

```python
print("x의 0 개수:", (df["x"] == 0).sum())
print("y의 0 개수:", (df["y"] == 0).sum())
print("z의 0 개수:", (df["z"] == 0).sum())
```

여러 컬럼을 동시에 선택하면 더 간단하게 작성할 수 있다.

```python
(df[["x", "y", "z"]] == 0).sum()
```

기본 diamonds 데이터셋 기준 결과:

```text
x     8
y     7
z    20
```

각 컬럼에서 0인 값의 개수를 확인할 수 있다.

다만 하나의 행에서 여러 컬럼이 동시에 0일 수 있으므로 각 컬럼의 개수를 단순히 더하면 중복 계산이 발생할 수 있다.

### 4. 조건 연산자

| 연산자 | 의미 |
|---|---|
| == | 값이 같다 |
| != | 값이 다르다 |
| > | 초과 |
| >= | 이상 |
| & | AND, 모든 조건 만족 |
| \| | OR, 하나 이상의 조건 만족 |
| ~ | NOT, 조건 결과 반전 |

```python
bad = (df["x"] == 0) | (df["y"] == 0) | (df["z"] == 0)
```

x, y, z 중 하나라도 0인 행을 True로 반환한다.

```python
bad.sum()  # 조건에 해당하는 행의 개수
df[bad]    # 조건에 해당하는 행 조회
df[~bad]   # 조건에 해당하지 않는 행 조회
```

bad는 Pandas에서 제공하는 명령어가 아니라 직접 선언한 변수이다.

### 5. 비정상적으로 큰 치수 확인

y 또는 z가 20mm를 초과하는 행을 직접 조회한다.

```python
bad_size = (df["y"] > 20) | (df["z"] > 20)

df[bad_size]
```

필요한 컬럼만 확인할 수도 있다.

```python
df.loc[bad_size, ["carat", "x", "y", "z", "price"]]
```

**이상치라고 판단하는 이유**

다이아몬드의 무게와 길이, 너비, 깊이는 서로 관련이 있다. 특정 치수만 다른 치수에 비해 지나치게 크다면 물리적으로 불균형한 형태를 나타내므로 측정 오류 또는 데이터 입력 오류일 가능성이 있다.

단순히 수치가 크다는 이유만으로 제거하는 것이 아니라 다른 컬럼의 값과 함께 비교하여 판단해야 한다.

### 6. 이상치 제거 및 데이터 복사

x, y, z 중 하나라도 0이거나 y, z 중 하나라도 20mm를 초과하는 행을 제거한다.

```python
bad = (
    (df["x"] == 0) |
    (df["y"] == 0) |
    (df["z"] == 0) |
    (df["y"] > 20) |
    (df["z"] > 20)
)

print("제거할 행:", bad.sum())

df_clean = df[~bad].copy()

print("제거 전:", len(df))
print("제거 후:", len(df_clean))
print("제거된 행:", len(df) - len(df_clean))
```

기본 데이터셋 기준 예상 결과:

```text
제거 전: 53940
제거 후: 53917
제거된 행: 23
```

copy()를 사용하면 원본 데이터를 유지하면서 전처리된 데이터를 독립적으로 관리할 수 있다.

## 4장. 난수 생성과 데이터 샘플링

### 1. Seed(시드)의 개념

시드는 난수 생성 알고리즘에 전달하는 초기값이다.

```python
rng = np.random.default_rng(40)
```

40은 생성할 데이터의 개수가 아니라 난수 생성의 초기값이다.

동일한 시드로 난수 생성기를 초기화하고 동일한 순서로 함수를 실행하면 같은 난수 결과를 재현할 수 있다.

머신러닝에서는 실험 결과의 재현성(Reproducibility)을 확보하기 위해 사용한다.

### 2. 균등분포 (Uniform Distribution)

```python
rng = np.random.default_rng(40)

area = rng.uniform(20, 85, 200)
```

20부터 85 사이의 균등분포에서 난수 200개를 생성한다.

균등분포는 동일한 길이의 구간에서 값이 발생할 확률이 동일한 분포이다.

### 3. 정규분포 (Normal Distribution)

```python
noise = rng.normal(0, 2500, 200)
```

| 매개변수 | 의미 |
|---|---|
| 0 | 평균 |
| 2500 | 표준편차 |
| 200 | 생성할 난수 개수 |

정규분포는 평균을 중심으로 데이터가 집중되는 종 모양의 확률분포이다.

실제 데이터에 존재하는 불규칙한 오차를 표현하기 위해 활용할 수 있다.

### 4. 데이터 샘플링 (Sampling)

전체 데이터 중 일부 데이터를 무작위로 추출하는 작업이다.

```python
rng = np.random.default_rng(40)

idx = rng.choice(
    len(df_clean),
    size=3000,
    replace=False
)

df_sample = df_clean.iloc[idx]
```

| 코드 | 설명 |
|---|---|
| choice() | 무작위 데이터 추출 |
| len(df_clean) | 전체 데이터 개수 |
| size=3000 | 추출할 데이터 개수 |
| replace=False | 중복 추출 방지 |
| iloc[] | 정수 위치를 기준으로 데이터 선택 |

Pandas의 sample()을 이용하여 더 간단하게 작성할 수도 있다.

```python
df_sample = df_clean.sample(
    n=3000,
    random_state=40
)
```

데이터가 지나치게 많으면 산점도에서 점들이 겹칠 수 있으므로 일부 데이터를 샘플링하여 시각화할 수 있다.

## 5장. 상관관계 분석 (Correlation)

### 1. 숫자형 컬럼 선택

```python
df_clean.select_dtypes("number")
```

문자형 또는 범주형 컬럼을 제외하고 정수형, 실수형 등 숫자 자료형의 컬럼만 선택한다.

### 2. 데이터 정렬

```python
df_clean["price"].sort_values(ascending=False)
```

| 옵션 | 의미 |
|---|---|
| ascending=True | 오름차순 |
| ascending=False | 내림차순 |

SQL의 ORDER BY ASC, ORDER BY DESC와 비슷한 기능이다.

### 3. 상관계수 계산

상관계수는 두 변수 사이의 선형적인 관계의 방향과 강도를 수치로 나타낸 값이다.

```python
df_clean["carat"].corr(df_clean["price"])
```

기본적으로 Pearson 상관계수를 계산한다.

| 상관계수 | 의미 |
|---|---|
| 1에 가까움 | 강한 양의 선형 상관관계 |
| 0에 가까움 | 선형 상관관계가 약함 |
| -1에 가까움 | 강한 음의 선형 상관관계 |

상관계수가 0이라고 해서 두 변수 사이에 모든 종류의 관계가 없다는 뜻은 아니다.

### 4. 가격과 관련된 상관계수 정렬

```python
df_clean.select_dtypes("number").corr()["price"].sort_values(
    ascending=False
)
```

**실행 순서**

1. select_dtypes("number"): 숫자형 컬럼 선택
2. corr(): 컬럼 간 상관계수 계산
3. ["price"]: 가격과 관련된 상관계수 선택
4. sort_values(): 상관계수 내림차순 정렬

상관관계 분석을 통해 가격 예측에 활용할 수 있는 특성(Feature)을 탐색할 수 있다.

단, 상관관계가 높다고 해서 반드시 인과관계가 존재하는 것은 아니다.

## 8장. 선형 회귀 (Linear Regression)

### 1. 선형 회귀란?

선형 회귀는 입력 데이터와 결과 데이터 사이의 관계를 직선으로 표현하고, 새로운 입력값에 대한 결과를 예측하는 지도학습 알고리즘이다.

```text
y = wx + b
```

모델은 학습 데이터를 이용하여 실제값과 예측값 사이의 제곱 오차가 작아지는 방향으로 기울기와 절편을 결정한다.

### 2. Scikit-learn

Scikit-learn은 Python에서 머신러닝 모델의 학습, 예측, 평가 등을 수행할 수 있도록 제공하는 라이브러리이다.

```python
from sklearn.linear_model import LinearRegression
```

### 3. 입력 데이터와 정답 데이터 분리

```python
X = office[["area"]]
y = office["price"]
```

| 구분 | 설명 |
|---|---|
| X | 입력 데이터(Feature) |
| y | 예측 대상(Target) |

X는 면적, y는 가격으로 설정한다.

**대괄호 한 개와 두 개의 차이**

```python
office["area"]    # Series (1차원)
office[["area"]]  # DataFrame (2차원)
```

Scikit-learn의 입력 데이터 X는 일반적으로 2차원 형태가 필요하므로 대괄호를 두 번 사용한다.

### 4. 모델 생성 및 학습

```python
model = LinearRegression()

model.fit(X, y)
```

- LinearRegression(): 선형 회귀 모델 생성
- fit(): 입력 데이터와 정답을 이용하여 모델 학습

모델이 면적과 가격 사이의 관계를 학습한다.

### 5. 학습 결과 확인

```python
print(f"기울기 w = {model.coef_[0]} 정답: 450")
print(f"절편 b = {model.intercept_} 정답: 5000")
```

실제 실습 결과:

| 구분 | 데이터 생성 시 설정값 | 모델 학습값 |

학습된 모델의 공식:


가상 데이터를 생성할 때 무작위 오차와 특이 매물을 추가했기 때문에 학습된 기울기와 절편이 최초 설정값과 정확하게 일치하지 않는다.

## 9장. 머신러닝 모델 성능 평가

모델이 예측한 값과 실제값을 비교하여 모델의 성능을 평가할 수 있다.

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    root_mean_squared_error,
    r2_score
)
```

### 1. MAE (Mean Absolute Error)

평균 절대 오차이다.

실제값과 예측값의 차이에 절댓값을 적용한 후 평균을 계산한다.

```python
mean_absolute_error(y, y_pred)
```

```text
MAE = |실제값 - 예측값|의 평균
```

모델이 평균적으로 얼마나 틀리는지 확인할 수 있으며 원본 데이터와 단위가 동일하다.

값이 작을수록 좋다.

### 2. MSE (Mean Squared Error)

평균 제곱 오차이다.

실제값과 예측값의 차이를 제곱한 후 평균을 계산한다.

```python
mean_squared_error(y, y_pred)
```

```text
MSE = (실제값 - 예측값)²의 평균
```

오차를 제곱하기 때문에 큰 오차에 더 큰 영향을 받는다.

원본 데이터와 단위가 다르며 값이 작을수록 좋다.

### 3. RMSE (Root Mean Squared Error)

평균 제곱근 오차이다.

MSE에 제곱근을 적용하여 원본 데이터와 동일한 단위로 변환한다.

```python
root_mean_squared_error(y, y_pred)
```

```text
RMSE = √MSE
```

큰 오차에 민감하며 원본 데이터와 단위가 같기 때문에 MSE보다 직관적으로 해석할 수 있다.

### 4. R² Score (결정계수)

모델이 실제 데이터의 변동을 얼마나 잘 설명하는지 나타내는 평가 지표이다.

```python
r2_score(y, y_pred)
```

| R² 값 | 의미 |
|---|---|
| 1 | 실제값과 예측값이 완전히 일치 |
| 1에 가까움 | 데이터 변동을 잘 설명 |
| 0 | 평균값으로 예측하는 수준 |
| 0 미만 | 평균값으로 예측하는 것보다 성능이 낮음 |

R²는 정확도(Accuracy)와 다른 개념이며 음수가 나올 수도 있다.

### 5. 전체 모델 성능 평가 코드

```python
print(f"MAE = {mean_absolute_error(y, y_pred):,.0f}")

print(f"MSE = {mean_squared_error(y, y_pred):,.0f}")

print(f"RMSE = {root_mean_squared_error(y, y_pred):,.0f}")

print(f"R_SCORE = {r2_score(y, y_pred):.3f}")
```

실제 실습 결과:

```text
MAE = 2,493
MSE = 16,240,971
RMSE = 4,030
R_SCORE = 0.803
```

### 6. 평가 지표 비교

| 평가 지표 | 실습 결과 | 평가 기준 |
|---|---:|---|
| MAE | 2,493 | 작을수록 좋음 |
| MSE | 16,240,971 | 작을수록 좋음 |
| RMSE | 4,030 | 작을수록 좋음 |
| R² | 0.803 | 1에 가까울수록 좋음 |

MAE를 통해 평균적인 절대 예측 오차가 약 2,493이라는 것을 확인하였다.

RMSE가 MAE보다 크게 나타난 것은 큰 예측 오차가 존재한다는 점을 보여준다.

R²는 약 0.803으로, 현재 평가 데이터의 가격 변동 중 약 80.3%를 모델이 설명한다는 의미이다.

## 11장. 강화학습 (Reinforcement Learning)

### 1. 강화학습의 개념

강화학습은 에이전트가 특정 상태에서 행동을 수행하고, 환경으로부터 보상을 받으며 행동 전략을 지속적으로 업데이트하는 학습 방법이다.

당장의 보상만을 크게 만드는 것이 아니라 장기적인 누적 보상을 최대화하는 것을 목표로 한다.

```text
현재 상태(State)
      ↓
에이전트의 행동(Action)
      ↓
환경(Environment)
      ↓
보상(Reward) 및 다음 상태
      ↓
행동 전략 업데이트
      ↓
반복 학습
```

### 2. 강화학습의 구성 요소

| 구성 요소 | 설명 |
|---|---|
| Agent | 행동을 선택하고 학습하는 주체 |
| Environment | 에이전트가 상호작용하는 환경 |
| State | 현재 상황 또는 상태 |
| Action | 에이전트가 수행하는 행동 |
| Reward | 행동에 따라 제공되는 보상 |
| Policy | 상태에 따라 행동을 선택하는 전략 |

### 3. 강화학습의 핵심 요소 2가지

**① Exploration (탐험)**

아직 충분히 시도하지 않은 행동을 수행하면서 더 좋은 보상을 얻을 수 있는 방법을 탐색하는 것이다.

새로운 행동을 시도하기 때문에 실패할 가능성도 있지만 더 높은 보상을 발견할 수 있다.

**② Exploitation (활용)**

지금까지 학습한 경험을 바탕으로 가장 높은 보상이 기대되는 행동을 선택하는 것이다.

안정적인 보상을 얻을 수 있지만 새로운 행동을 발견할 기회를 놓칠 수 있다.

### 4. 탐험과 활용의 균형

| 구분 | 예시 |
|---|---|
| Exploration | 새로운 음식점을 방문하여 더 맛있는 음식을 찾음 |
| Exploitation | 이미 맛있다고 알고 있는 음식점을 방문함 |

강화학습에서는 탐험과 활용의 균형을 유지하는 것이 중요하다.

이를 Exploration-Exploitation Trade-off라고 한다.

### 5. 누적 보상의 중요성

| 행동 | 즉각적인 보상 | 미래 보상 | 총보상 |
|---|---:|---:|---:|
| A | 10 | 0 | 10 |
| B | 2 | 100 | 102 |

미래 보상을 할인하지 않는 단순한 예시에서 행동 B는 당장의 보상이 작지만 장기적으로 더 높은 보상을 얻을 수 있다.

강화학습은 이러한 장기적인 관점에서 유리한 행동 전략을 학습한다.

## 15장. 오늘의 느낀 점

어제는 머신러닝의 기본 개념과 데이터 탐색 방법을 학습하였다면, 오늘은 실제 데이터를 전처리하고 시각화한 뒤 머신러닝 모델을 학습시키는 과정까지 실습하였다.

특히 Pandas의 Boolean Mask를 활용하여 조건에 해당하는 데이터를 추출하고, 이상치를 제거하는 과정에서 데이터 전처리의 중요성을 이해할 수 있었다.

처음에는 난수 생성 시 사용하는 Seed가 데이터의 개수를 의미한다고 생각했지만, 동일한 실험 결과를 재현하기 위한 초기값이라는 것을 알게 되었다.

선형 회귀 모델을 직접 생성하고 학습시키면서 입력값과 정답 사이의 관계를 컴퓨터가 학습하고, 새로운 데이터에 대한 결과를 예측할 수 있다는 점이 흥미로웠다.

또한 특이 매물을 평가 대상에서 제외했을 때 모델의 평가 지표가 달라지는 것을 확인하면서 데이터의 특성이 머신러닝 모델의 성능 평가에 큰 영향을 준다는 것을 배웠다.

앞으로는 단순히 머신러닝 라이브러리의 함수를 사용하는 것에 그치지 않고, 각 함수의 동작 원리와 모델의 학습 과정, 성능 평가 지표의 의미까지 이해하면서 공부하고자 한다.
