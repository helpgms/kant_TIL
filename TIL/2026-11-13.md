## Docker CLI 명령어

### 컨테이너 목록 조회
```sh
docker ps   
```
### 컨테이너 실행(구동), 올린다, 로드한다.
```sh
docker run -d --name my-pg -e POSTGRES_PASSWORD=1234 -p 5432:5432 postgres:18

docker run -d --name my-pg \
-e POSTGRES_PASSWORD=1234 \
-p 5432:5432 postgres:18
```
### 정지된 컨테이너 목록까지 조회
```sh
docker ps -a
```
### 외부 SQL 파일을 도커 컨테이너 내부로 복사
```sh
docker cp kant_shop.sql(대상 파일) my-pg(컨테이너 명):/tmp/kant_shop.sql(복사파일) 
```

```sh

docker exec -it my-pg psql -U postgres -f //tmp/kant_shop.sql
```


### 데이터베이스를 선택(지정) 접속 및 확인
```sh
docker exec -it my-pg psql -U postgres -d kant_shop
SELECT * FROM product; (확인)
```

### 컨테이너를 삭제해도 안에 있는 데이터들은 남기고 싶을 때 볼륨 활용(필수)
```sh
- docker volume ls -> 확인
- docker volume create pgdata(볼륨이름) -> 생성
- docker volume inspect pgdata(볼륨명) -> 상세 정보 확인
```
- 기본 컨테이너 생성 시에 볼륨을 연결
```sh
docker run -d --name my-pg -e POSTGRES_PASSWORD=1234 -p 5432:5432 -v pgdata:/var/lib/postgresql postgres:18
```

- 컨테이너 삭제 후 볼륨 연결 확인
```sh
docker exec -it my-pg psql -U postgres -d kant_shop -c "SELECT * FROM product"
```
```sh
- 어떤 컨테이너에도 쓰지 않는 익명 볼륨 정리: docker volume prune
```

### compose 하는 방법
```sh
services:                 # 실행할 컨테이너(서비스) 목록 — 필수
  서비스이름:              # 예: db, web (직접 정하는 이름)
    image: 이미지:태그      # 사용할 이미지
    container_name: 이름   # 컨테이너 이름 (생략 시 자동 생성)
    environment:           # 환경 변수 (-e)
      KEY: value
    ports:                 # 포트 연결 (-p) — 문자열로 감싸는 것을 권장
      - "호스트:컨테이너"
    volumes:               # 볼륨 연결 (-v)
      - 볼륨이름:컨테이너경로

volumes:                  # 사용할 볼륨 선언 (최상위)
  볼륨이름:

- 후 확인 방법 : docker compose config
```
```sh
- 컨테이너에 올리는 방법 : docker compose up -d
- 컨테이너에서 없애는 법 : docker compose down
- 올라왔는지 안올라왔는지 확인하는 방법: docker compose ps
```

### 이제 연동하는 것을 해보자
```sh
- DBcode - SQL 이거를 설치
- 연동하고자 하는 sql 선택 (postgreSQL)
- 컨테이너 명 지정, localhost : 포트 번호(5432), 이미 설정한 유저명, 비번, 이미 만든 DB refresh 해서 검색.
```
---
```
도커 실습을 쭉 혼자 따라해보면서 정말 어려웠던 것 같다.
그러나, 해보면서 느꼈다. 손으로 계속 쳐보면서 외우려고 했던 걸 후회한다. 
코드 한줄을 차례대로 언어처럼 생각하고 읽어보면 된다.
예를 들면, docker run -d --name my-pg -e POSTGRES_PASSWORD=1234 -p 5432:5432 -v pgdata:/var/lib/postgresql postgres:18 이런 문장이 있다고 하면
한 단어씩 해석해보자.
도커에서 실행하라 -d 뒤에서 이름은 my-pg로 하고 환경은 POSTGRES 여기서 비밀번호는 1234로, 그거에 포트번호는 외부는 5432 내부는 5432 이고, 볼륨 아까 볼륨에 저장한 pgdata에서 그 파일 루트는 :/var/lib/postgresql에 있고, 그거에 대한 이미지명은 postgres:18이다.
```

```
한 줄씩 해석하면 이렇게 된다. 만약, 이것을 따라쓰는 것이 아니라 내가 생성해야한다면, 한 줄 한 줄 이렇게 생각하면서 작성하면 쉬울 것 같다.
앞서 파이썬도 마찬가지이다. 본인은 원래 쭉 머리에서 한번에 하려고 하는 습관이 있는데 그럴때마다 처음에는 엄청 벽을 느낀다. 하지만, 이번엔 한 줄 한 줄 하면서 더 필요한 것들을 찾게 되고, 그것을 빨리 찾아 이후에는 오류와 부족한 점을 빠르게 채워나갈 수 있게 되었다.
전에 전공 수업을 들으면서, 교수님이 이런 적이 있다. 언어를 처음 배울 때, 코드 전체를 외우려고 한다고, 맞다, 처음엔 이해가 안되서 외우려고 시도했다. 그러면서 익숙해지면서 쉬운 코드들은 외울 수 있었고, 머리 속으로 한번에 그릴 수 있었다.
하지만, 코테를 준비했을 때와 지금은 그리 간단한 코드만을 치는 건 아니였다. 앞으로도, 한 줄 한 줄하는 것으로 바꾸려고 노력해야겠다.
```
