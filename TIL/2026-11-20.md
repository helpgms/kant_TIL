## 1. NumPy란?

**NumPy(Numerical Python)** 는 Python에서 숫자 데이터를 효율적으로 처리하기 위한 라이브러리이다.

- 다차원 배열(Array)을 생성하고 관리할 수 있다.
- 1차원, 2차원 등 다양한 형태의 배열을 다룰 수 있다.
- 수학 및 통계 연산을 빠르게 수행할 수 있다.

### 1차원 배열과 2차원 배열

```python
import numpy as np

# 1차원 배열
arr1 = np.array([1, 2, 3, 4])

# 2차원 배열
arr2 = np.array([[1, 2], [3, 4]])

print(arr1)
print(arr2)
```

**출력 결과**

```text
[1 2 3 4]

[[1 2]
 [3 4]]
```

NumPy는 1차원 배열을 단순히 2차원으로 보여주는 라이브러리가 아니라, **다차원 배열을 다루는 라이브러리**이다.

## 2. Pandas란?

**Pandas**는 데이터를 분석하고 가공하기 위한 Python 라이브러리이다.

NumPy를 기반으로 만들어졌으며, 표 형태의 데이터를 쉽게 처리할 수 있다.

주요 기능은 다음과 같다.

- 데이터 조회 및 분석
- 데이터 정렬 및 필터링
- 결측치 처리
- CSV, Excel 등의 데이터 읽기 및 저장

### NumPy와 Pandas 비교

| 구분 | NumPy | Pandas |
|---|---|---|
| 주요 목적 | 수치 계산 | 데이터 분석 및 가공 |
| 대표 자료구조 | ndarray | Series, DataFrame |
| 특징 | 다차원 배열 연산 | 행과 열을 이용한 데이터 처리 |

## 3. NumPy, Pandas 설치

프로젝트 터미널에서 다음 명령어를 실행한다.

```bash

```

- `pandas` : 데이터 분석 및 처리

실행 결과로 각 라이브러리의 버전이 출력되면 정상적으로 설치된 것이다.

## 5. zip() 함수

`zip()`은 여러 개의 반복 가능한 데이터를 같은 위치끼리 묶어주는 Python 내장 함수이다.

### 예제

```python
names = ["철수", "영희", "민수"]
scores = [90, 85, 95]

result = list(zip(names, scores))

print(result)
```

**출력 결과**

```text
[('철수', 90), ('영희', 85), ('민수', 95)]
```

각 리스트의 동일한 인덱스에 있는 값들이 하나의 튜플로 묶인다.

### 반복문에서 활용

```python
for name, score in zip(names, scores):
    print(name, score)
```

**출력 결과**

```text
철수 90
영희 85
민수 95
```

`zip()`은 데이터 길이가 서로 다르면 기본적으로 가장 짧은 데이터의 길이에 맞춰 묶는다.

## 6. Pandas의 핵심 자료구조

Pandas에서 중요한 자료구조는 **Series와 DataFrame**이다.

### ① Series

Series는 1차원 데이터 구조이다.

하나의 열(Column)을 표현할 때 주로 사용한다.

```python
import pandas as pd

spend = pd.DataFrame({
    "name": ["철수", "영희", "민수"],
    "amounts": [10000, 20000, 30000]
})

print(spend["amounts"])
```

**출력 결과**

```text
0    10000
1    20000
2    30000
Name: amounts, dtype: int64
```

`spend["amounts"]`는 `amounts` 컬럼 하나를 선택하므로 Series 형태로 반환된다.

### ② DataFrame

DataFrame은 행(Row)과 열(Column)로 이루어진 2차원 데이터 구조이다.

```python
print(spend)
```

**출력 결과**

```text
  name  amounts
0   철수    10000
1   영희    20000
2   민수    30000
```

### 여러 컬럼 가져오기

여러 컬럼을 가져오려면 대괄호를 두 번 사용한다.

```python
print(spend[["name", "amounts"]])
```

- `spend["amounts"]` : 하나의 컬럼 선택 → Series
- `spend[["name", "amounts"]]` : 여러 컬럼 선택 → DataFrame

**대괄호가 두 개인 이유**

바깥쪽 `[]`는 DataFrame에서 컬럼을 선택하는 역할을 하고, 안쪽 `[]`는 선택할 컬럼 이름들을 리스트로 전달하는 역할을 한다.
